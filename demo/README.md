# Demo samples

The receipts visitors can try in demo mode, built by `scripts/build_demo.py` from stored results, so showing them calls no provider.

## Attribution

The images in `images/` are from the [CORD dataset](https://github.com/clovaai/cord) by Park et al., ["CORD: A Consolidated Receipt Dataset for Post-OCR Parsing"](https://github.com/clovaai/cord) (2019), licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/) and provided without warranty.

**Changes made:** resized to at most 1400 pixels on the long side and recompressed as JPEG. The answers in `samples.json` were produced by the extraction providers, not by the dataset's authors.
